# 南坡小炒——Spring Boot 课程学生手册

> 主线项目：为成都理工大学工程技术学院南坡的一家小炒饭馆，开发一套点餐系统。
> 你将从零开始，二十次课把它从"一行开业标语"做成"能用 AI 点单、一条命令部署"的完整系统。

## 怎么使用这套手册

每课三个文件，按顺序读、按顺序做：

| 文件 | 内容 | 什么时候看 |
|---|---|---|
| `01-课程导入.md` | 故事背景、本课目标、课前检查 | 动手前 |
| `02-动手做.md` | 逐步操作 + 完整代码 + 每步原因 + 常见报错 | 跟着做 |
| `03-验证提交练习.md` | 验证清单（命令+预期输出）、git 提交、课后练习 | 做完后 |

**规矩**：每课做完必须验证全部通过、git 提交并打 tag，才算"下课"。课程代码是连续演进的——上一课的代码就是下一课的起点，跳课会做不下去。

## 课程地图

| 阶段 | 课次 | 你的店会变成 |
|---|---|---|
| 开店迎客 | 1-2 | 能发请求、能点成一单、有个简陋网页 |
| 分工与店规 | 3-6 | 分层架构、IoC、统一返回、统一异常 |
| 建账本 | 7-12 | H2 数据库、JPA、订单落库、事务、分页 |
| 照片与会员 | 13-16 | 菜品图片上传、登录令牌 |
| AI 与开店 | 17-20 | Spring AI 点单、Docker 部署、新框架巡礼 |

## 环境要求（第 1 课开始前装好）

- JDK 17+
- IntelliJ IDEA **Ultimate**（自带 HTTP Client）或 VS Code + **REST Client** 插件
- 浏览器（访问 start.spring.io 生成项目骨架；课后也可以用浏览器直接访问接口）
- 网络（首次构建要下载依赖）

## 接口验证方式

全课程统一用项目根目录的 **`requests.http`**（REST Client 格式）：第 1 课创建，之后每课往里追加请求。启动程序 → 打开文件 → 点请求上方的运行按钮即可发送，响应在编辑器侧边面板查看。

## 查看每课的"标准答案"

课程仓库带 tag：`lesson-01` ~ `lesson-20`。

```bash
git tag                          # 看所有课程节点
git show lesson-01               # 看第1课的提交详情
git diff lesson-01 lesson-02     # 看第1→2课的代码变化
git checkout lesson-01           # 回到第1课下课时的项目状态（看完 git checkout main 回来）
```
